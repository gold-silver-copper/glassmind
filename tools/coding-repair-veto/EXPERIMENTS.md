# Retained experiments and limitations

The earlier universal positive whitelist remains rejected: original independent
explicit repairs8→4; widening restored8/8+15legacy but full765 fell180→53.
No version of that whitelist is part of this patch. Its historical reports and
all old68 inputs/labels are untouched. No parent/* independent cases were read.

This batch froze PLAN and32 contrasts before runtime changes. The nine-case
native baseline completed before implementation: six unrequested edits. A full
baseline typing run was started before runtime editing against the compiled old
source, but was slow in debug. The redundant debug baseline/intermediate runs
were explicitly stopped within their owned scopes and superseded by complete
optimized typing runs against the exact baseline source at6a346c3 and final
source, using unchanged release libraries. Thus full172 baseline results were
available after implementation began, not before. No claim otherwise.

First intermediate status override failed the existing exact-reading preservation
test. Matching old status readings now survive unchanged. The archived first
candidate test binary reproduces the failure in first-candidate-exact-failure.log.
The original debug first-candidate logs were interrupted, not passing runs.

Second intermediate candidate misread a diagnostic noun `check` as a requested
check and lost one of159 baseline TRAIN typed repairs. Retained frozen source,
binary and typing in rejected-check-noun; full results in candidate-optimized.json.
Check requests now require a directive/question root. This is a syntactic-role
correction, not an exemption for the training sentence.

Supplemental9 contrasts were authored after implementation and are explicitly
not the preregistered32. They found a baseline-positive regression: cognitive
`don't get why` was treated as a prohibited repair result. Frozen source/binary,
full native and typed results remain in rejected-cognitive-get. `get` with an
interrogative complement (why/how/what) now has a distinct role in polarity and
reported-speech analysis. Final source is rerun on all287 original typed rows,
all9 supplemental rows, the complete native115 plus supplemental9, and the
original package tests. No initial or intermediate native run is final evidence.

The first optimized adapter compilation failed because a relative include_str
path to the unchanged coding model was not relocated. Only that path in the
generated adapter was changed to absolute; runtime weights were never modified.
No score was reported for those failed compile attempts.

Known limits: this is a bounded explicit speech-act veto, not an authorization
proof for all English. Existing implicit reports and underspecified requests
retain legacy Repair candidates. Old68 still has one pre-existing positive
refusal and four negative typed-expectation failures (three actually edit in do).
The action/modifier vocabulary and question grammar are finite; unsupported
status tails veto Repair rather than infer a new status meaning. Quoted names
and diagnostics stay data; ordinary positive inference remains legacy/model
behavior. All172 TRAIN requests are coverage diagnostics, not permission labels;
the overt-marker/implicit column is a lexical diagnostic, not ground truth.

Parent full765 preservation, the separately frozen independent explicit probes,
and the exact nine historical parent unrequested edits have NOT been run here.
This candidate must be rejected if those frozen gates fail; local improvement
does not authorize integration or publication.
