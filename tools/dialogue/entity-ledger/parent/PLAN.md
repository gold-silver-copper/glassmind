# Independent fresh-entity contracts

Freeze six fictional entity names, including Unicode, in paired immediate and
delayed-reference conversations. Four controls cover competing alternatives and
explicit rejection/negation. These are authored probes, not official held-out
data or evidence of broad accuracy. No worker source or result has been inspected.

Run the approved baseline on speaker/utterance-only inputs. A candidate must
preserve every baseline-correct destination, produce no incorrect additional
destination on the twelve positives, correctly fill at least two delayed
references, and leave all four control destination states identical to baseline.
An abstention remains allowed on the remaining positives. Inspect exact source
provenance for each new binding after the candidate's metadata format is known;
the texts, intended referents and acceptance rule remain fixed. Baseline mistakes
are disclosed, not counted as candidate successes. Other service predictions must
remain consistent with the candidate's frozen router/intent invariants.

Also verify per-conversation reset, order independence, annotation rejection and
legacy model equivalence using the established adapters. The unchanged full DEV
gate remains >=620/1119 joint, >=726/1218 frames, all610/716 retained, zero newly
wrong scored assertions. No runtime or expected-result changes based on outcomes.
