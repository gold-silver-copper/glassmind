## Exact implementation

- New `src/argument_swap.rs`: resolve root same-file free functions with exactly two equal primitive scalar parameter types. Operands must be typed parameters, directly resolved primitive fields of typed struct parameters, explicitly typed scalar literals, or parenthesized versions. No inferred locals, overloaded operations, custom scalar types, methods, generic/imported/external calls or side-effecting operands are lowered.
- Reject shadowed callees/operands, unsupported scopes, imports, root aliases, opaque attributes and uncertain macro bindings. Parse only bare standard `format!` with a literal string and simple `{}` positional placeholders / escaped braces. Traverse parsed expression arguments; retain literal/macro bytes, operand bytes and inter-argument comments/trivia. No textual search replacement.
- `checks.rs`: append swaps globally after every existing proposal family, including ceiling division. Preserve legacy first-pass search and native-confirmed scalar veto. For a passing NEW swap only, test remaining NEW alternatives, declining two passing alternatives or incomplete bounded verification (max eight follow-ups, ten seconds, existing overall budget). No scalar-call interpreter extension and no invented semantic witness. New swaps cannot withdraw a legacy patch.
- `lib.rs`: register the module. New structural tests cover exact spans/refusals and cross-file priority. Authored contracts and offline native replayers live under the owned tools directory.
