Frozen scope supplement before implementation of ellipsis: TRAIN Problem wording
supports independently expressed conditional facts, passive completion queries,
and local verb/work ellipsis. Elliptical `B in 6 days` inherits only the preceding
completion operation/work, not its agent or time. Query `B alone can do it in?`
binds a missing duration slot; `how long will they take` requires a separate
explicit simultaneous condition and a unique local workload. A group subject
completing one workload in one time denotes collective completion; multiple times
bind in textual agent order. No stage, partial workload, number-selection, or
whole-question production. Inflected completion verbs normalize to typed actions.
Explicit state in a conditional concerns actual simultaneous operation; solo
`fill an empty tank` is intentionally not promoted to an initial-state assertion.
