# TRAIN-only shared operand ranker preregistration

Hypothesis: shared candidate-relative scoring of explicit surface quantity roles and relationships transfers operand binding across numeric positions better than independent 42-way positional heads. This is a bounded representation experiment, never production acceptance.

Frozen before candidate implementation and CAL inference: use exact original TRAIN normalized-question split (23912 FIT / 5925 CAL), unchanged parser, numeric binder, execution and typed label comparator. Clean memberships must be 4590/1182, preserving all exclusions. Original first 200 CAL reproduction is an instrumentation check required before fitting: exact parsed original/native and reused decoder outputs including scores.

Representation: number mentions retain native spans; punctuation-delimited clauses; surface entity/unit candidates from alphabetic material after a mention up to next mention or clause boundary; predicate-context candidates from clause alphabetic material before mention. These are ambiguous surface candidates, NOT POS/dependency parses or semantic rules. Missing sets remain explicit. Candidate features share weights across all input indices; surface roles, clause bags, cue overlap with question-final clause, same-clause and surface-role overlaps with selected left, numeric shape/rank, used-in-prefix and prior-step ancestry/operation/recency. Constants use their existing typed identity; prior steps use operation and descendant mention role unions. No operator/answer phrase whitelist. No vocabulary fit on CAL; deterministic 65536-bin feature hashing with inspectable feature strings. Side/operation and depth conjunctions share one linear ranker; no per-input-index weight banks. Original operation head stays byte-identical. Only operand scoring changes. Original masks, greedy ascending ties, horizon 6, STOP and rational execution remain unchanged.

One configuration: 10 epochs, fixed input order, multiclass softmax SGD learning rate 0.20, sqrt(feature-count) normalization, zero initialization, no tuning, early stopping, averaging or CAL selection. Gold-context operand alignments only from clean FIT. Shared hashed weight vector serialized <=16MiB. Training <=600s, <=8GiB, no swap, one process. If insufficient time or defensibility, mark incomplete/rejected.

Evaluate all clean FIT and CAL free exact AST / native numeric / refusal / wrong, teacher left given gold operation+prefix, teacher right given gold operation+left+prefix, gold-plan+length oracle with predicted arguments/prefix and explicit forced STOP at gold length (max6). Frozen nonSTOP operation teacher numerator 1912/4138 CAL. Per-step/operator/input-count, whole-row all-arguments-correct, distributions, baseline/candidate records. Free input accepts JSON strings only and is evaluated independently from gold. Candidate/oracle scores use same softmax log-score convention. Baseline first200 must match exactly before proceeding.

Continuation gate (not shipping): CAL left >=56.09%, right >=63.39%, oracle numeric>=251/1182, free numeric>=143/1182. Baselines 2197/4138 left,2499/4138 right,143 free,221 oracle. Failure rejects; gates never reduced. No DEV or held-out access, no parent semantic cases, downloads/model calls/agents/services/commits. Only tools/quantities/role-binding owned; external RUN evidence allowed. Preserve all failures. Freeze final source, model, commands, logs, inputs, outputs and manifest into RUN/frozen-candidate.
