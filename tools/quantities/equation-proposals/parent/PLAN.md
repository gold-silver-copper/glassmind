# Parent independent proposal contracts, frozen before candidate inspection

24 semantic questions with independently calculated rational answers. The repeated
number/role/direction variants are explicit, not extracted from MathQA evaluation.
Measure raw and selected results separately. Require at least12/24 raw correct and
no selected error on the paired reversed ratio, comparison and rate questions.
Report every mismatch and selection decision; unverified outputs do not become
correct just because their arithmetic executes. These authored checks are not an
independent benchmark or a guarantee of English entailment.

Eight number-binding/execution contracts pin literal UTF-8 byte spans, duplicate
positions, signed/decimal/comma/fraction values and division by zero. Seven invalid
program contracts require graceful rejection without panic or an invented value.
Schema adapters may be written after frozen worker inspection; do not change these
questions/programs/expected values to fit the candidate. If the public API does not
expose program execution, construct a declared synthetic model fixture after schema
inspection to exercise the same native executor, independent of learned rankings.

All proposed replies must explicitly remain unverified. Default solve remains
unchanged. Model load/bounds additionally check oversized payloads, invalid weights,
unknown program versions/operations and source offset validity as the API permits.
Do not count an unavailable command as a baseline accuracy score. This is a new
representation experiment, not the rejected rate-grammar revisions.
